
# hydotfiles

## what is this repo

This repo is my hyprland lua dotfiles with noctalia.
The install script also installs all my needed packages. This repo is probably not for you!

It used to be a fork of project hyde but it no longer is, as migrating to lua was too much work  
and now I am using noctalia shell.

## Installation

run the following commands:
```
git clone https://github.con/schmynth/hydotfiles
cd hydotfiles/
./install.sh
```
After rebooting, run
```
cd hydotfiles/
./install.sh -f
```
in order to finish the installation.
